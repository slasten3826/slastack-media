# slasten visual corpus

This directory is the visual payload for `slastack` visual crystall research.

It corresponds to:

- main stack document: `research/memoris/VISUAL_CRYSTALL.md`
- main stack index: `media/slasten/MANIFEST.md`

## Structure

- [table](table/) — addressable expressive field
- [crystall](crystall/) — crystallized manifestation examples

GitHub URLs:

- [table](https://github.com/slasten3826/slastack-media/tree/main/slasten/table)
- [crystall](https://github.com/slasten3826/slastack-media/tree/main/slasten/crystall)

## table

`table/` contains expressive fragments and stable visual components:

- face states
- gestures
- posture variants
- emotional range
- props and small scene fragments
- repeatable palette and silhouette signals

Read it as visual table, not as final outputs.

## crystall

`crystall/` contains assembled visual manifestations:

- role scenes
- style variants
- context-bearing images
- generated outputs that preserve recognizable character structure

Read it as evidence of runtime crystallization.

## Policy

This payload is not canonical by itself.
The canonical interpretation lives in the main `slastack` repository.

Preserve directory structure.
The directory structure is part of the evidence.
