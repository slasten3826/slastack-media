# slastack-media

Media payload repository for `slastack`.

This repository stores visual corpora and other heavy media payloads that should not live inside the main `slastack` git history.

Main stack:

- https://github.com/slasten3826/slastack

## Reading Rule

Do not read this repository by default.

Use it only when the main stack points to a media corpus and the task requires visual inspection.

The main `slastack` repository remains the canonical markdown / topology / research surface.
This repository is payload.
